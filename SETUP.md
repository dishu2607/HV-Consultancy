# Contact form → private Google Sheet (no email, ever)

The Contact section (`src/sections/Contact.jsx`) does not send email to
anyone. It posts straight to a Google Apps Script "Web App" endpoint that
appends a row to a Google Sheet only you have access to. The visitor only
ever sees the on-screen "Message received" confirmation.

## 1. Create the Sheet

1. Go to sheets.google.com → **Blank spreadsheet**.
2. Rename it, e.g. `HV Consultancy — Enquiries`.
3. In row 1, add headers: `Timestamp | Name | Email | Message | Followed up?`.

## 2. Add the Apps Script

1. In the Sheet: **Extensions → Apps Script**.
2. Delete anything in the editor and paste this:

```javascript
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var p = e.parameter;

  // Human-readable timestamp (e.g. "3 Sep 2026, 6:05 PM"), in the
  // spreadsheet's own timezone — not a raw ISO string. Uses the
  // server's clock at the moment it's received, not the visitor's.
  var timestamp = Utilities.formatDate(
    new Date(),
    Session.getScriptTimeZone(),
    "d MMM yyyy, h:mm a"
  );

  sheet.appendRow([
    timestamp,
    p.name || "",
    p.email || "",
    p.message || "",
  ]);

  // Add an unchecked checkbox in the same row (column E — "Followed up?"),
  // so you can tick it off once you've replied.
  var lastRow = sheet.getLastRow();
  sheet.getRange(lastRow, 5).insertCheckboxes().setValue(false);

  return ContentService.createTextOutput(
    JSON.stringify({ ok: true })
  ).setMimeType(ContentService.MimeType.JSON);
}
```

3. Save the project (name it anything, e.g. `hv-enquiries-webhook`).

By default `Session.getScriptTimeZone()` matches the Sheet's own timezone
setting. To confirm or change it: **File → Settings → General → Time zone**
in the Sheet, and re-deploy after any change (see step 3 below).

## 3. Deploy it as a Web App

1. Top right: **Deploy → New deployment**.
2. Click the gear icon next to "Select type" → **Web app**.
3. Set:
   - **Execute as:** Me (your Google account)
   - **Who has access:** Anyone
   (This does *not* make the Sheet public — it only lets the deployed
   script accept form submissions. Only you can open the Sheet itself.)
4. Click **Deploy**, authorize the permissions Google asks for.
5. Copy the URL it gives you — it ends in `/exec`.

## 4. Wire it into the site

Open `src/sections/Contact.jsx` and replace the placeholder:

```javascript
const SHEET_ENDPOINT = "https://script.google.com/macros/s/REPLACE_WITH_YOUR_DEPLOYMENT_ID/exec";
```

with the URL you copied.

That's it — every submission lands as a new row in your Sheet, in real
time, and the visitor only ever sees the in-page confirmation.

### Notes

- The request is sent in `no-cors` mode (Apps Script doesn't return CORS
  headers), so the site can't read the response back — it treats "the
  request went out" as success. If you want a real success/failure signal,
  you'd need to put the Apps Script behind something that adds CORS headers
  (e.g. a Cloudflare Worker in front of it), which is a bigger change.
- A hidden honeypot field (`company_website`) is already wired in to catch
  basic spam bots, since "Anyone" access means the endpoint is public.
- If you'd rather not use Google Sheets at all, the same `fetch(...)` call
  can point at any endpoint that accepts a POST and writes a row somewhere
  (Airtable, a small serverless function, etc.) — only the URL and the
  field names would need to change.
- The timestamp is generated by the script itself, not the browser — so it
  reflects when the message was received, in the Sheet's timezone, and
  can't be spoofed or thrown off by a visitor's device clock.
- Every time you edit the script (including copying in an update from
  here), you need to **Deploy → Manage deployments → edit (pencil) →
  New version → Deploy** for the change to actually take effect — saving
  the file alone doesn't update the live `/exec` endpoint.
- The checkbox is inserted per-row after the fact, so it stays a real
  checkbox (not just the text "TRUE"/"FALSE") and defaults to unchecked
  for every new enquiry.
